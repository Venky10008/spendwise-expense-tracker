# Task 4 tests

Put this folder in the root of the repo, next to js/ and tests/.

Run everything:

    node tests-task4/run-all.js

Files:

- edge.js: edge cases for amounts, dates, validation, filter, sort, CSV
- integration.js: store and storage working together, with a fake localStorage
- performance.js: timing with 10,000 expenses
- system.html: open it in Chrome, it fills the real form and shows the result at the top
- helper.js, run-all.js: small helpers

The full list of test cases is in Task4_Test_Case_Matrix.csv.
